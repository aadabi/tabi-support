# Tabi support

Public support and privacy pages for the Tabi Japan itinerary-planning app, provided by AI 2 X Co.

- Support: https://aadabi.github.io/tabi-support/
- Privacy policy: https://aadabi.github.io/tabi-support/privacy.html
- Support requests: https://github.com/aadabi/tabi-support/issues

This repository contains the public website only. It does not contain application source code, private App Review contact details, user backups, or credentials.

The site is static HTML/CSS with no analytics or tracking scripts. GitHub Pages publishes the root of the main branch.

Please do not post personal travel, health, booking, or contact information in public issues.
